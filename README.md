가족끼리 사용할 아이의 숙제관리 apk를 만들어보고 싶어

  - 진행 배경 : 아이가 학교와 학원에서 많은 숙제를 받아오는데 제대로 관리가 되지 않아.
                    날짜별로 숙제를 입력하고 완료여부를 포함한 진행여부, 데드라인 임박상황등을 부모와 같이 공유하고 싶어.
  - 프로그램 구조 : 아이가 바라보는 뷰와 부모가 바라보는 뷰가 다를텐데 별도의 apk를 가져가고 싶지는 않아.
                          그냥 진입시에 1번 아이(채이현)이냐 학부모(아빠/엄마)냐 를 한번 선택하면 될 것 같아.
                          가능할지 모르겠지만 아이가 숙제를 등록하거나 각 숙제의 상태가 변경되면 
                          부모에게도 같이 업데이트가 오면 좋겠어.
                          스마트폰 권한문제는 모두 허용할 예정이라 걱정할 필요는 없을 것 같아.
  - 아이 화면 주요 기능 
         : 달력을 기반으로 숙제를 등록하게 하는 화면이 필요해. 숙제의 주요 카테고리는 학교/영어/수학/그외 야.
         : "학교"는 영업일 기준 매일 입력, "영어"는 화/목/토, "수학"은 월/수/금, "그외"는 필수는 아니야.
         : 처리 기한은 "학교는" 바로 다음 영업일, "영어" 차주 화요일, "수학"은 바로 다음수업, "그외" 별도로 입력받아야 해
         : 등록된 항목별로 진척관리가 필요해. 숙제가 없을 경우도 없음을 등록해야하고, 등록/진행/완료 상태에 진행인 경우 진척률도 등록되면 좋겠어
         : 화면 동선을 추천받았으면 좋겠는데 D-DAY별로 완료되지 않은 숙제를 보여줘서 해야할 우선순위를 정해주면 좋겠어.

  - 부모 화면 주요기능
        : 아이가 숙제를 등록했는지, 등록한 숙제의 진척이 얼마나 되는지, 완료를 했는지를 확인하는 대시보드 형태가 제공되면 좋겠어
        : 등록하고 이후 상태가 변화되면 알림도 오면 좋겠어.

이러한 구조의 프로그램 구성이 가능할지 알려주고
클로드코드에 사용할 claude.md과 skill.md파일 구성해줘.
